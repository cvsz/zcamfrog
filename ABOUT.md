# About — Camfrog Multi-ID Manager

Windows WPF desktop application (`.NET 8`, `win-x64` self-contained)
for managing multiple local Camfrog client identities: isolated
profiles, DPAPI-protected passwords, process-lifecycle safety,
optional Sandboxie-Plus multi-instance support, and `camfrog:` room
auto-join.

- Repository: `https://github.com/cvsz/zcamfrog`
- License: MIT (`LICENSE`), copyright 2026 cvsz
- Maintainer: [@cvsz](https://github.com/cvsz)
- Security: see `SECURITY.md` (private reports only, never public issues)

What this project is **not**: a Camfrog client, a bot framework, or a
way to bypass authentication, licensing, or paid features. It launches
the third-party client you installed and tracks it safely.
